## Visual Examples

The `images/` subdirectory contains reference figures and animations generated by `examples/generate_documentation_images.py`:

- **Cell System Example** (`images/cell_system_example.png`) — Discrete cell states (`Empty`, `Quiet`, `Moving`, `Divided`) with Node 7 polarization compass arrows alongside SGF and LGF concentration fields ($\nabla \text{LGF}$ gradient vectors).
- **Morphogenesis Timelapse** (`images/morphogenesis_timelapse.gif`) — Animated GIF exported via `TimelapseExporter` showing multicellular morphogenesis from a single mother cell.
- **Network Example** (`images/network_example.png`) — Directed recurrent gene regulatory network with functional node classes (`0..7` + hidden) and signed excitatory/inhibitory regulatory edges.
- **Phase-Space & Homeostasis Comparison** (`images/phase_space_example.png`) — 2D `(SGF, LGF)` steady-state decision map (`Die`, `Quiet`, `Move`, `Split`) paired with midpoint occupancy ($S_{T/2}$), final occupancy ($S_T$), and structural delta ($|S_{T/2} - S_T|$).
- **Evolution Example** (`images/evolution_example.png`) — Best and mean shape homeostasis fitness progression ($F \in [0, 1]$) across generations of the genetic algorithm.

To regenerate these figures locally:

```bash
uv run python examples/generate_documentation_images.py
```

## Continuous Integration and Testing

Automated GitHub Actions workflows run on free `ubuntu-latest` runners with path filters to avoid redundant builds on unrelated edits:

- **Lint & Unit Tests (`.github/workflows/ci.yml`)**: Triggered on changes to Python packages (`core/`, `evolution/`, `visualization/`, `analysis/`, `examples/`), `config/`, `scripts/`, `tests/`, `pyproject.toml`, or `ci.yml` (skipping docs-only updates). Validates shell scripts (`bash -n`), runs `ruff check`, compiles Python bytecode, and runs `pytest -v` under `MPLBACKEND=Agg`.
- **Docker Build & Smoke Check (`.github/workflows/docker.yml`)**: Triggered only on changes to `Dockerfile`, `.dockerignore`, `docker-compose.yml`, `pyproject.toml`, container scripts (`scripts/run_container.sh`, `scripts/teardown_container.sh`), or `docker.yml` (plus manual `workflow_dispatch`). Builds `grn-simulation:ci` with Buildx layer caching and verifies package imports inside the container.

To run all checks locally with `uv`:

```bash
uv sync --dev
uv run ruff check .
uv run pytest -v
```
